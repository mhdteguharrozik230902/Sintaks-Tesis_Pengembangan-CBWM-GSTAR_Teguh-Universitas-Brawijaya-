# Sintaks-Tesis_Pengembangan-CBWM-GSTAR_Teguh-Universitas-Brawijaya-
This project explores the integration of Spatiotemporal Density-Based Spatial Clustering of Applications with Noise (ST-DBSCAN), Cluster-Based Weight Matrix (CBWM), and Generalized Space-Time Autoregressive (GSTAR) models to analyze and forecast poverty rates across six provinces in Sulawesi, Indonesia.
